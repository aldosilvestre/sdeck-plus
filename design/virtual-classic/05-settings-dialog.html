05 · Menu switch and settings dialog

App side of the virtual deck: the menu keeps a short switch plus "Virtual deck settings…", which opens a dialog with the address, QR, certificate, password, port and viewers.

Tradeoff
  • The menu stays short; the dialog has room for a larger QR, a scrolling viewer list and "Disconnect all".
  • One more click to reach the address and viewers; the header status ("Virtual deck on · 2 viewers") opens the same dialog.
  • The warning about command keys is shown where the password is set.
