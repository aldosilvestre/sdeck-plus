04 · All in the menu

App side of the virtual deck: the flag and everything it needs (address, QR, password, port, viewers) live in the header menu, below the existing items.

Tradeoff
  • One place, no extra window; the switch and its consequences are seen together.
  • The menu grows to ~700 px while on; with more than four viewers the list scrolls inside the menu.
  • Changing the password disconnects every viewer (asked in a confirm dialog).
  • Turning the switch on serves the page without opening a browser window (Open or the QR code does); turning it off stops the server and drops the device.
  • The page is plain HTTP on the local network: no certificate, so no fingerprint to show.
